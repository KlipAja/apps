Pertanyaan yang Sering Diajukan

Apakah saya harus bisa coding atau instal Python?

Sama sekali TIDAK! KlipAja Studio berbentuk file installer Windows .exe biasa. Anda cukup mengklik dua kali file installer, dan aplikasi langsung terpasang di komputer dengan icon shortcut di Desktop. Tidak ada terminal hitam atau script rumit.

Apakah ada biaya tambahan untuk AI-nya?

KlipAja Studio menggunakan sistem Bring Your Own Key. Di dalam paket pembelian, kami sudah sertakan panduan cara mendaftar kunci API resmi dari Groq Cloud dan Google Gemini secara 100% GRATIS tanpa perlu memasukkan kartu kredit sama sekali.

Bagaimana sistem lisensinya bekerja?

Setiap lisensi dikunci pada ID perangkat unik (HWID) laptop/PC Anda. Saat pertama kali dibuka, aplikasi akan menampilkan kode HWID Anda. Anda cukup kirimkan kode itu ke WhatsApp kami, dan kami akan berikan kode aktivasi resmi untuk membuka akses permanen seumur hidup.

Apa spesifikasi komputer yang disarankan?

Sistem operasi Windows 10 atau Windows 11 (64-bit), prosesor Intel Core i3 / AMD Ryzen 3 ke atas, RAM minimal 4 GB (disarankan 8 GB), dan sisa ruang hard disk minimal 2 GB.

Bagaimana jika saya ganti laptop atau install ulang Windows?

Jangan khawatir! Cukup hubungi admin kami melalui WhatsApp dengan melampirkan bukti pembelian, dan kami akan membantu memindahkan atau mereset kode aktivasi ke perangkat baru Anda tanpa biaya tambahan.
